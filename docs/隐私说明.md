# 数据与隐私

疾览不需要登录账号，也不要求付费接口。当前版本源码没有内置遥测、分析上报、广告、在线更新器或 HTTP 请求客户端。

## 本机保存

文件名称索引、位置配置、最近搜索、收藏搜索和工作区会话保存在 `~/Library/Application Support/QuickFind`。这些数据包含名称、路径和使用记录，请像其他本机个人资料一样保管。它们不会由疾览上传至 GitHub，也不包含在安装包或公开源码中。

建立索引会读取目录项和文件名称、路径及必要属性，不读取文件内容进行全文索引。大小、日期和隐藏属性筛选按需访问实际文件的属性。

## 打开、预览与整理

Quick Look 预览会由 macOS 读取所选文件内容；打开文件交给系统默认关联应用。复制和跨磁盘移动会读取并写入文件内容，改名、移动、新建文件夹和移至废纸篓会实际改变所选文件。是否允许访问这些文件由 macOS 权限和你发起的操作决定。

你主动打开开源声明中的上游网站时，链接交给默认浏览器。你主动添加网络目录或使用云同步文件时，系统文件服务、浏览器、Quick Look 扩展或关联应用可能按各自规则联网；这不属于疾览向项目服务器上传索引。

## 反馈时注意

截图、验证报告和问题路径可能包含个人信息。提交 Issues 前请使用自建样例并遮挡真实个人路径与文件名，不要上传索引、位置配置、工作区数据、账号凭据或完整未脱敏报告。
