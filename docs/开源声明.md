## 实际复用

- 上游项目：[FuzzyIdeas/Cling](https://github.com/FuzzyIdeas/Cling)
- 固定源码提交：`60c3570e4d278ac4be519b9c72221dda784ad132`
- 来源文件：`Cling/SearchEngine.swift`
- 上游许可证：GNU GPL v3，随项目保存于 `LICENSE`。
- 本地留存原始文件：`vendor/Cling/SearchEngine.original.swift`，仅用于溯源，不参与编译。

`Sources/SearchEngine.swift` 实际移植了上游的 SIMD 字节查找、字符掩码预筛、连续 UTF-8 字节数组索引、路径增删和空槽复用设计。不是简单列举项目名称后独立重写。

适配改动包括：默认连续片段、多关键词 AND、名称与路径搜索分开、Unicode NFC/NFD 归一化、扩展名准确过滤、全量匹配计数、后台变更的存储压缩、SHA-256 校验、边界检查和原子保存。二进制格式重新定义，不与 Cling 缓存互通。

2.0 保留 1.0.1 的 qfi 兼容性与常见查询快速路径，新增组合条件字节谓词、扩展名 ID 与取消配合。实际大小和修改日期在独立后台读取，不属于上游名称索引内容。

中文 AppKit 界面、磁盘与文件夹管理、FSEvents 协调、启动和磁盘重连校准、扫描问题提示、Quick Look、快捷键、构建及验证由本项目实现。2.0 的高级解析/属性筛选、双栏多标签、收藏、会话保存、临时集合和文件任务服务，也由本项目实现。

2.1 继续复用上述本项目成果，将搜索结果嵌入左栏固定标签，顶部常驻搜索与筛选，右栏保留实际目标目录，并直接联动选择、共享预览和文件任务。2.1.1 在现有索引更新、查询调度与界面刷新上修复静置跳动，未新增第三方运行依赖，也未改变 Cling 来源提交或许可。

2.2 在现有搜索、属性缓存和收藏机制上扩展可视化筛选、递归条件组、多目录范围、创建日期及隐藏/连接状态，沿用 AppKit 原生控件和 Foundation 日期、属性读取；未增加第三方运行依赖，Cling 来源提交及整体 GPL-3.0-only 许可保持。

2.2.1 将产品名更新为「疾览 · Jilan」，添加作者署名「by 塔贰舅」，保留原应用身份、数据位置、搜索与文件管理实现及上游许可声明。

2.2.2 在上述索引核心上增加父目录前缀共享和紧凑文件名存储，以散列桶及原路径核对保留准确的路径身份；名称查询沿用 SIMD 预筛，属性候选以同一索引快照计数并分批串流。扫描使用新索引自身去重，文件事件合并为有界待处理批次，目录读取和结果属性后台任务增加取消与容量保护。沿用原 qfi 缓存兼容性、应用身份和数据位置，未增加第三方运行依赖，固定上游提交及 GPL-3.0-only 许可保持不变。

本版还修复磁盘挂载通知的范围判断，仅校准相关索引位置，避免无关安装映像触发全部位置扫描；未增加第三方依赖。

上游完整应用中的授权系统、联网分享、脚本执行、第三方更新器和关联 SDK 未纳入。2.0 的复制、移动、单项/批量改名、新建文件夹和废纸篓使用自主编写的 FileOperations.swift、DirectoryBrowser.swift、WorkspaceController.swift，没有移植上游文件管理流程。本应用使用苹果系统框架 Foundation、AppKit、Quartz/Quick Look、Carbon、CoreServices、CryptoKit 与 Darwin 文件接口，不依赖付费接口、账号或下载后的第三方运行库。
