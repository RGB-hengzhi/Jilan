# 疾览 · Jilan 文件拖放说明

适用于 2.2.4（构建 11）及后续版本。本版将目录列表已有的原生文件拖出功能接入搜索结果。

## 从搜索结果拖到其他应用

1. 在疾览中输入名称，找到要使用的文件。
2. 打开目标应用，将聊天窗口、附件接收区或其他支持文件拖放的位置放在可见处。
3. 按住搜索结果行中的名称或图标，将它拖到目标位置后松开鼠标。
4. 查看目标应用是否显示附件或接收结果；需要发送或提交时，在目标应用中确认。

例如，可尝试把搜到的文件拖到微信聊天窗口或 ChatGPT 的附件接收区。不同客户端、版本和接收位置的支持范围可能不同；没有出现接收提示时，先确认拖放位置及目标应用允许的文件类型和大小。

拖出多个文件时，先按住 `⌘` 逐个选择，或用 `⇧` 选择连续结果，再从已选中的结果行开始拖动。目录标签中的文件列表也可按同样方式拖出。

疾览提供的是 macOS 原生文件 URL 拖放，不是文件名文本或截图。准备拖出时不读取文件内容，也不提前复制文件；拖出操作保留原文件，不会把本地原件移走。目标应用自行决定怎样读取、复制或添加附件；有些应用会在接收附件时直接开始上传，请先确认所选文件和接收位置。

## 文件不可用时

名称索引可能仍保留已经无法访问的条目。以下情况不能作为有效文件拖出：

- 文件所在的索引位置已断开，例如外置硬盘未连接。
- 文件已经删除，或已经改名、移动，而名称索引尚未同步。
- 当前用户或疾览没有读取该文件的权限。

搜索结果在开始拖动时捕获所选项目的原文件路径，并整批检查。只要其中任一项不可用，就取消整次拖出，在窗口底部显示原因，不会悄悄跳过部分文件。查看提示、检查选择后再尝试。

遇到这些情况，先连接原磁盘、确认原文件仍存在，或按实际需要授予访问权限，再尝试拖出。读取名称索引不等于拥有原文件的读取权限；拖放不会绕过 macOS 的权限检查。

## 接收范围与注意事项

- 文件格式、大小、数量和文件夹能否接收，由目标应用决定。目标应用不支持的格式，不会因为从疾览拖出而获得支持。
- 搜索结果是跨目录集合，不能当作存放文件的实际目录，也不能用作拖入文件的目标。
- 拖到疾览另一栏的实际目录时，沿用文件管理的复制流程；需要移动原件时，请明确使用「移动到另一栏」等移动操作。
- 目标应用会获得你所选文件的本地 URL，并可能读取或上传文件内容。拖出前确认所选项目和目标窗口；不要把不打算分享的文件一起选入。

这份说明介绍疾览提供的拖放接口与使用方法，不表示所有第三方客户端、文件格式或接收位置均已逐一验证。
