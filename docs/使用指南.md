# 疾览使用指南

## 即时搜索

在顶部输入文件或文件夹名称片段，结果随输入更新，无需按回车开始搜索。空格分隔的关键词必须同时匹配，英文大小写不敏感。默认只匹配名称，勾选「同时匹配路径」可让父目录名称参与匹配。

| 示例 | 含义 |
| --- | --- |
| `合同 2026` | 名称同时包含两个片段。 |
| `ext:pdf,docx` | PDF 或 DOCX。 |
| `*.pdf` | 通配符匹配整个名称。 |
| `合同 !草稿` | 包含合同，排除草稿。 |
| `(合同 \| 协议) ext:pdf` | PDF 合同或协议。 |
| `"年度 合同"` | 将带空格片段作为一个连续条件。 |
| `size:>100mb` | 大于 100 MB。 |
| `dm:today` / `dc:today` | 今天修改 / 今天创建。 |
| `dm:2026-01-01..2026-12-31` | 修改日期范围，包含结束日。 |

「更多筛选」可设置大小与日期范围、多目录包含/排除、隐藏与磁盘状态，以及「全部满足」「任一满足」的嵌套条件组。条件标签可单独移除；「清空筛选」保留顶部关键词。

默认首批显示 2,000 项，「显示更多」每次增加 5,000 项。表头排序仅针对已加载结果。大小与日期在后台读取：首批最多检查 20,000 个名称候选，点击「检查全部候选」可继续完整检查；未知、离线和未检查项目分别标记。文件夹大小不递归计算，正则表达式尚未提供。

## 搜索后直接整理

左栏有固定「搜索结果」与实际目录标签；右栏是目标目录，可保留多个标签。

1. 在右栏路径框进入目标目录。
2. 在左栏选中搜索结果，Command 或 Shift 多选。
3. 使用「复制到另一栏」或「移动到另一栏」，检查任务进度与结果。

点击某栏使它成为当前操作栏，蓝色边框与「●」标示当前栏。复制/移动以当前栏选中项目为来源，另一栏实际目录为目标。搜索结果是集合，不能当作粘贴、新建文件夹或拖入的目标。

单项改名输入完整名称，包括扩展名；批量改名先预览，再确认，保留文件扩展名。移至废纸篓可在 Finder 中恢复。整批整理没有一次性撤销。

遇到重名可保留两份、跳过、替换或取消。替换前的原目标会留在同卷恢复目录，完成后使用「查看恢复备份」定位；应用不自动清空备份。跨盘移动先复制并核对来源，再移除源项目；出现仅复制或未完成提示时，应核对两份文件。

## 常用快捷键

| 快捷键 | 操作 |
| --- | --- |
| Control + Option + 空格 | 呼出搜索窗口（应用运行期间）。 |
| Command + F | 回到全盘搜索。 |
| Command + 1 | 目录浏览。 |
| 回车 / 双击 | 打开选中结果；文件夹在应用内浏览。 |
| Command + 回车 | 在 Finder 中显示。 |
| Command + Shift + C | 复制完整路径。 |
| 空格 | 快速预览。 |
| Command + C / X / V | 文件列表中的复制 / 剪切 / 粘贴。 |
| Command + T / W | 新目录标签 / 关闭当前目录标签。 |
| F2 | 改名。 |
| Command + Delete | 移至废纸篓。 |
| Command + Q | 退出应用并保存索引变化。 |

中文输入法组词期间，回车先用于确认选词；搜索尚未完成或没有匹配时，不会打开旧结果。关闭窗口后应用仍在菜单栏运行，可从菜单栏重新打开。

## 索引范围与权限

顶部「索引位置」显示位置侧栏，可添加文件夹、索引当前本地磁盘、重新扫描或移除某个索引。移除索引不删除原文件。

首次扫描会遍历可读取的位置。隐藏文件和应用包内部项目会收录；符号链接收录链接本身，不遍历其目标；系统虚拟目录、重复卷入口跳过；网络共享盘不在自动发现范围内。

「就绪（部分位置受限）」和「查看未覆盖路径」表示仍有未读取目录。权限、磁盘离线或扫描超时都可能造成未覆盖。只有实际读取并索引的位置能够搜索；已有缓存中的名称也可能因离线、删除或当前权限不足而暂时无法打开。

需要扩大受保护目录的覆盖时，从「疾览」菜单进入「完全磁盘访问权限…」，由你在系统设置中添加并启用实际安装的疾览应用。权限是否授予由你决定；按系统提示重启应用后重新扫描。普通文件、文件夹和可移除宗卷的访问请求同样由 macOS 管理。

外置盘离线时保留名称缓存，实际打开与整理需重新连接；接回后等待校准。全盘索引不等于拥有全盘读取权限，也不意味着与 Windows NTFS 的 Everything 索引机制相同。
