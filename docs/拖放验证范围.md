# 2.2.4 文件拖放验证范围

版本：2.2.4（构建 11）；本轮验证日期：2026-10-13。

## 已完成的验证

- 完整自动回归通过，包含使用真实私有 `NSPasteboard` 进行的文件 URL 写入、读取与多文件检查。
- 原生测试应用中，搜索结果拖出经过实际的 AppKit 拖放源回调，检查所选文件路径、拖出准备和操作类型。
- 在实际应用窗口间，将自建的、文件名包含 Unicode 字符与空格的 TXT 文件从搜索结果拖到 Chrome 测试接收区；接收区取得真实文件，拖放完成操作为 `.copy`。
- 上述拖放后，来源文件仍存在，文件内容字节保持不变。

自动回归和原生测试覆盖拖放源的实现；Chrome 接收测试证明本轮测试文件能够通过真实跨应用文件拖放被接收。这些结果不等于所有第三方应用、文件类型、数量或文件夹均已通过验证。
