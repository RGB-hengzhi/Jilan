# 疾览 · Jilan 安装说明

by 塔贰舅 · 免费使用 · GPL-3.0 开源

本说明对应 2.2.2（构建 9），更新日期：2026-10-04。

适用设备：Apple Silicon Mac（M 系列芯片），macOS 14 或更新版本。

项目页面：https://github.com/RGB-hengzhi/Jilan

正式下载：https://github.com/RGB-hengzhi/Jilan/releases/latest

## 安装

1. 打开 `Jilan-2.2.2-macOS-arm64.dmg`。
2. 将「疾览.app」拖入旁边的「Applications」快捷方式。
3. 等待复制完成，在 Finder 左侧推出「疾览 Jilan」磁盘映像。
4. 打开「应用程序」，双击「疾览」。

## 第一次打开

这个免费发行版使用本地 ad hoc 签名，尚未使用 Apple Developer ID 签名，也未经过 Apple 公证。

如果系统提示无法验证开发者或 Apple 无法检查此应用，请先确认安装包来自项目的正式发布页面，并核对该页面提供的 SHA-256 校验值。然后按照 Apple 的官方步骤操作：先尝试打开应用，再进入「系统设置 → 隐私与安全性」，在对应提示旁点击「仍要打开」，并确认「打开」。组织管理的 Mac 可能由管理员限制此操作。

如果系统明确提示应用损坏或将损坏电脑，请停止安装，重新下载并核对发布校验值，向项目反馈提示内容。

Apple 官方说明：https://support.apple.com/zh-cn/102445

## 搜索与文件管理

首次使用时，添加要索引的磁盘或文件夹。索引完成后，在顶部输入文件名即可即时筛选，搜索结果和双栏文件管理可以一起使用。

macOS 可能为桌面、文稿、下载或外置磁盘分别询问访问权限，请根据你选择的索引范围决定是否允许。受限路径会在应用内显示；没有授权的位置无法保证完整搜索。是否授予「完全磁盘访问权限」由你决定，安装包不会修改系统权限。

索引和偏好保存在你本机，不包含在此安装包中。软件不会把你的文件名称索引上传到 GitHub。更新应用时先退出旧版，再替换「应用程序」中的应用；应用身份和数据位置沿用，已有索引和偏好无需随安装包搬运。
